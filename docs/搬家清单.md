# 搬家清单：从移动硬盘搬到内置硬盘

> 写给「下次搬家的人」—— 包括未来的我。按这里做，5 分钟搬完，不会把垃圾一起拖过去。

## 一、为什么要搬

项目现在放在移动硬盘（ExFAT）上，2026-10-30 实测到的三个真问题：

| 问题 | 实测 | 后果 |
| --- | --- | --- |
| 小文件慢 5 倍 | 300 个文件：98ms（ExFAT）对 20ms（内置 APFS） | 浏览器自检要写几千张截图 + Chrome 几万个小文件，最容易把 USB 通道写满、整盘卡住 |
| macOS 影子文件 | 清出 **12473 个 `._*`，12.7 GB** | 和真文件同后缀，被测试当成 js 模块/文案/下载的备份读 → **本机红、CI 绿的假红**（今天中了三次） |
| 没有日志 | ExFAT 无 journal | 写一半拔盘/断电，`.git` 可能坏（当天已出现 `._` 混进 refs，`git fsck` 报 `badRefName`） |

结论：**能搬就搬**。搬不了也不致命，但每次跑完整自检前先清一次 `.audit`，并且跑的时候别拔盘、别让电脑休眠。

## 二、怎么搬（推荐：clone，别整目录拷）

整目录拷会把 20 多 GB 的垃圾和一万多个影子文件一起带过去。

```bash
mkdir -p ~/Projects
cd ~/Projects
git clone https://github.com/kotochain/fatloss-helper.git
cd fatloss-helper
```

### 仓库外要单独带走的三样

| 东西 | 为什么 | 命令 |
| --- | --- | --- |
| `.workbuddy/memory/` | 项目记忆（每天的日志、踩过的坑），新会话靠它接上前几轮 | `cp -R "<旧盘>/减脂工具/.workbuddy" .` |
| `data/ai-key.txt` | 一般**不存在**（密钥默认在 `~/.dsh/fatloss-ai-key`，跟项目无关）；存在才拷 | `cp "<旧盘>/减脂工具/data/ai-key.txt" data/ 2>/dev/null` |
| `.audit/*.md` 报告 | 可选。想留一份「上次检查结论」才拷，截图不用 | `mkdir -p .audit && cp "<旧盘>/减脂工具/.audit/"*.md .audit/` |

### 千万别拷

- `.audit/`（截图，16 GB 起）、`.selfcheck/`（旧 Chrome 资料，4 GB）
- 任何 `._*`（macOS 影子文件）、`.DS_Store`

## 三、搬完自检（三条）

```bash
npm test                              # 应当 370 个全过
git status                            # 应当干净；一堆 M 但 diff 为空 = 权限位，跑 git config core.filemode false
git fsck                              # 没有输出 = 仓库健康
```

## 四、搬完怎么开新会话

新会话只需要一句话：

> 接着做减脂工具

然后让它读这三份（路径相对新工作区）：

| 文件 | 作用 |
| --- | --- |
| `docs/交接速览.md` | 一屏看完当前状态，开场用 |
| `HANDOFF.md` | 完整交接：为什么这么做、怎么发版、踩过的坑 |
| `docs/产品逻辑总账.md` | 63 条产品规则，每条挂着一个能跑的测试 |

## 五、搬家后旧盘那份怎么办

留着当备份，但**不要两边都改** —— 会分叉。搬家完成后，旧盘那份只在「新位置出事」时用，并且先用 `git log` 对一下两边是不是同一个提交。

想彻底断掉影子文件，可以在盘根建个空文件（关掉 Spotlight 索引这块盘）：

```bash
touch /Volumes/PortableSSD/.metadata_never_index
```

## 六、这次搬家顺手做的加固（不用重做，已经在代码里）

- `tests/_files.mjs`：所有「扫目录」的测试跳过 `._*` / `.DS_Store`
- `tools/live-audit.mjs#downloadedJson`、`check-live`、`sweep-check`、`mutate-check`：同样跳过影子文件
- `.git/info/exclude` 加了 `._*`（只在本机，不进仓库）
