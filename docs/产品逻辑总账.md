# 产品逻辑总账

> **为什么有这张表**：同一类错误——「AI 只许给名字、不许估热量」——在文档里写了、在测试里"守着"，
> 却活了两轮才被推翻。原因是**没有一张能被审计的账**：规则散在提示词、注释、README、测试、HANDOFF 里，
> 改的时候没人能一眼看到「这条规则由谁守、有没有测试」。
>
> 维护规则：**新增或推翻一条产品规则时，先改这张表，再改代码。** 「测试」列写「无」的，
> 必须在文末「已知缺口」里点名，不能静默存在。

| 列 | 含义 |
| --- | --- |
| 承诺 | 使用者能感知到的一句话 |
| 代码 | 落实这条规则的源码位置（`文件#关键函数/常量`） |
| 测试 | 锁住它的测试（`文件#测试名关键词`）；「无」= 已知缺口 |
| 决策 | HANDOFF 里的决策编号；「未立项」= 还没写成决策 |
| 状态 | 有效 / 已推翻 / 待定 |
