# 给她用之前，你需要知道的 3 件事

## 1. 她需要先填 6 个数字
性别、年龄、身高、体重、平时活动量、想多快瘦。填完之后工具会算出：每天吃多少 kcal、蛋白/脂肪/碳水各多少克。

**活动量那一栏请往低了选。** 大多数人以为自己「中等活动」，实际是久坐。选高了会算多消耗，吃多了就不掉秤。

## 2. 真正管用的不是公式，是每周称体重
工具里所有公式都有 ±10% 的误差。所以「体重」页会在你记录两周之后告诉你：现在这个吃法掉秤速度是快是慢，该多吃还是少吃。**前两周的数字不用太当真，第二周开始看趋势。**

称体重要固定条件：早上起床、上完厕所、穿同样的衣服。

## 3. 第一周别急着改数据
让她先照推荐吃一周，只做记录、不改参数。一周之后看：
- 太饿 → 把「想快一点」改成「慢慢来」
- 掉太快（一周超过 1 公斤）→ 也要改成「慢慢来」
- 白天没力气 → 检查是不是主食（碳水）吃太少

## 常见问题

**记不记得住？**
这是最容易失败的地方。建议：只记「主食 + 肉蛋 + 油」这三类，蔬菜不用记（热量极低）。外食直接搜「家常菜/外食」分类里的近似条目。

**她不爱吃鸡胸肉怎么办？**
食物库里还有虾、巴沙鱼、龙利鱼、牛里脊、豆腐、鸡蛋、无糖酸奶。餐单页点「换一套」会换组合。也可以直接把鸡胸替成同等蛋白的其它肉，克数大约是：鸡胸 150 g ≈ 虾 190 g ≈ 龙利鱼 160 g ≈ 牛里脊 145 g。

**会不会伤身体？**
代码里写死了安全下限（女生每天不低于 1200 kcal、不低于基础代谢的 1.1 倍、每周掉秤不超过体重 1%、偏瘦不给缺口）。
但如果她怀孕/哺乳、有甲状腺或肾脏问题、在吃影响体重的药、或者不满 18 岁，**先问医生，不要用这个工具的数字**。

**数据会丢吗？**
存在她手机浏览器的本地存储里。清缓存、换手机会丢——所以「体重」页有「导出存档」，换了设备用「导入存档」恢复。
