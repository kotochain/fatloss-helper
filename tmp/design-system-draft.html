视觉系统设计稿

减脂小助手 · 2026-11 · 仅设计稿，不影响线上版本（v52）

1. 三条设计原则

先定方向，再定参数。所有具体值都从这里推导。

原则含义
一个主角每屏只有一块是「主角」（圆环 / 大数字 / 主按钮），其他一律降级。颜色、字重、尺寸都围绕这个层级分配。
少而准字号 17 种 → 5 种；字重 10 种 → 3 种；圆角 15 种 → 4 种。约束本身带来秩序感。
暖而不粉保留现在的暖米白基调，但把粉红「玫瑰色」从背景装饰收敛到「动作与强调」，大面积只用中性色。

2. 色彩系统

把硬编码的 rgba 变体收敛成语义 token。改主题色只动一行。

品牌色（动作与强调专用）

--brand主按钮、选中态、圆环
--brand-strong品牌文字（对比度更高）
--brand-soft选中底色、柔和强调
--brand-ghost次级按钮底（新）

语义状态色

--positive完成 / 达标 / 植物
--warning需要注意 / 历史日期
--danger超量 / 危险操作
--info说明 / 提示

中性色（大面积使用）

--ink主文字
--ink-2次级文字
--ink-3辅助文字
--bg页面底
--card卡片底
--surface-muted次级填充
--line分隔线

营养素三色（图表专用，不再挪作他用）

蛋白紫
脂肪金黄
碳水绿

3. 字号与字重

17 种字号 → 5 种；10 种字重 → 3 种。每一级有明确职责，不允许出现「差不多大」的两级并存。

Token值用途示例
--text-display44px / 700圆环中央大数字（全站唯一）1287
--text-title17px / 650卡片标题、弹层标题今天还剩多少
--text-body15px / 400~600正文、列表项、按钮鸡胸肉 150g · 248 千卡
--text-small13px / 400~600次级说明、胶囊、徽章练 32 分钟 · 231 千卡
--text-caption11.5px / 550标签、时间戳、图注昨晚 23:41 记录

字重只用三档：Regular 400（正文）、Semibold 600（标题/按钮/选中）、Bold 700（大数字）。 现在的 550/620/650/660/680/720 全部归并——中间档在屏幕上根本看不出差别，只会让代码变成抽奖。

4. 圆角、阴影与间距

圆角是这套 UI 的「字形」——大 = 容器，中 = 元素，小 = 微件，胶囊 = 标签。4 种，不许出现第 5 种。

Token值用于
--radius-lg18px卡片、hero 大区块
--radius-md13px按钮、输入框、弹层内分组、图表柱
--radius-sm9px小徽章、进度条段、色块小格
--radius-full999px胶囊、标签、头像

间距全部走 4px 网格：4 / 8 / 12 / 16 / 20 / 24。 现在的 9px 6px、8px 4px 这类手写组合全部归位到网格。

阴影只留两档：卡片微影（几乎看不见、只做分离）与弹层悬浮影。现在的 shadow-lift 和 shadow-overlay 已经是这两档，保留。

7. 明确不改的部分

视觉系统是「整理」，不是「重设计」。以下保持现状。

整体暖米白 + 玫瑰色的品牌气质v50~v52 已定的信息架构（折叠、分组、降权）
iOS 质感的模糊顶栏与底栏所有动效（用户已明确暂缓）
图标的线性风格与尺寸现有触控尺寸标准（40/44px 最小目标）
